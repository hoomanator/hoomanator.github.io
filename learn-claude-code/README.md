# Learning Claude Code — A Hands-On Course for Beginners

Welcome! This is a step-by-step, do-it-yourself course for learning **Claude Code**,
Anthropic's command-line coding assistant. There's no video, no slides — you'll spend
almost all your time in the terminal, typing real commands and watching real things
happen. That's the only way tool skills like this actually stick.

## Who this is for

You should be comfortable with:
- Opening a terminal and running basic commands (`cd`, `ls`, `mkdir`)
- The very basics of one programming language (we'll use Python, but you don't need
  to be good at it — just able to read simple scripts)

You do **not** need prior experience with AI tools, git, or any specific framework.

## How the course works

Each lesson lives in [`lessons/`](lessons/) and follows the same shape:

1. **Concept** — a short explanation of one new idea (kept brief on purpose)
2. **Hands-on** — exact steps to type into your terminal, with what you should see
3. **Try it yourself** — a small challenge with no exact answer given
4. **Checkpoint** — a quick self-check before moving on

Do the lessons in order. Each one builds on a project you create in Lesson 3 and
keep extending through the rest of the course. Budget 15–30 minutes per lesson.
