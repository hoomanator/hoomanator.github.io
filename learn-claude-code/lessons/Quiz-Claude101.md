How it works:
When you publish an Artifact in Claude, a unique public link is generated that you can share with others. Viewers can interact with the artifact and use the "Remix" button to copy it directly into their own Claude conversation to adapt, build upon, or modify it.

7. What data can Claude access through connectors?

- Only data created in the last 30 days
- All data in the connected service
- Only data you have permission to access
- Only docs that have been individually shared with Anthropic

Only data you have permission to access

How permissions work:
When you authorize a connector (like Google Drive, Slack, or GitHub), Claude acts under your account credentials via OAuth. It inherits your exact permissions from the connected service, meaning it can only view or retrieve files, messages, and records that you already have explicit authorization to see.
